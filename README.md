# Мне 22 года и я не знаю, что делать дальше

`index.html` — интерактивная схема связей российской элиты: 498 человек, 106 точек пересечения, 229 прямых связей. Оформлена по системе дизайна ШИБЕЙС (сервис «База знаний»): Acari Sans, Ambidexter для логотипа, светлая и тёмная темы. Открывается локально в браузере, нужен только интернет для загрузки d3.

- Вкладка «Ваш путь»: анкета по спецификации `data/anketa-i-rekomendacii.md`. 31 вопрос и 5 вопросов профиля, восемь осей, девять архетипов, подбор похожих людей из 109 размеченных биографий, советы с действием на 90 дней. Логика в `anketa.js`, расчёт идёт в браузере.
- Пять слоёв: ядро (98), первая сотня кандидатов (100), второй эшелон (100), третья сотня (100), четвёртая сотня (100).
- Восемь групп по способу входа в элиту, включая «Спорт, культура и медиа» из четвёртой сотни.
- Фильтры по группе, категории узла, надёжности данных, году рождения.
- Портреты 279 человек из Wikimedia Commons, с автором и лицензией в карточке и в сводке.
- Карточка человека: фото, сейчас, в 18–25 лет, взлёт, точки пересечения, прямые связи, с кем пересекается.
- «Как связаны»: кратчайшая цепочка между двумя людьми с пояснением каждого шага.
- Вкладка «Список»: сортируемая таблица со всеми карточками.
- Вкладка «Сводка»: статистика и выводы.

Источники данных: `data/dosye-elita.md`, `data/dosye-elita-tretya-sotnya.md` и `data/dosye-elita-chetvyortaya-sotnya.md`. Изменения анкеты относительно спецификации: `data/anketa-izmeneniya.md`. Шрифты системы дизайна в `fonts/`. Сборка описана в `tools/README.md`.

## Сборка и тесты

Страница собирается командой `tools/rebuild.sh`, подробности в `tools/README.md`. Тесты запускаются командой `npm test`, их состав описан в `tests/README.md`.

## Развёртывание

Как открыть сайт локально, выложить на свой сервер с nginx или на GitHub Pages: `DEPLOY.md`. Готовый конфиг nginx лежит в `deploy/nginx.conf`.
