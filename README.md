# Схема связей российской элиты

`index.html` — интерактивная схема: 298 человек, 87 точек пересечения, 140 прямых связей. Открывается локально в браузере, нужен только интернет для загрузки d3.

- Три слоя: ядро (98), первая сотня кандидатов (100), второй эшелон (100).
- Фильтры по группе, категории узла, надёжности данных, году рождения.
- Портреты 227 человек из Wikimedia Commons, с автором и лицензией в карточке и в сводке.
- Карточка человека: фото, сейчас, в 18–25 лет, взлёт, точки пересечения, прямые связи, с кем пересекается.
- «Как связаны»: кратчайшая цепочка между двумя людьми с пояснением каждого шага.
- Вкладка «Список»: сортируемая таблица со всеми карточками.
- Вкладка «Сводка»: статистика и выводы.

Источник данных: `data/dosye-elita.md`. Сборка описана в `tools/README.md`.
