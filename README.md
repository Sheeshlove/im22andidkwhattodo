# Мне 22 года и я не знаю, что делать дальше

`index.html` — интерактивная схема связей российской элиты: 398 человек, 98 точек пересечения, 182 прямые связи. Оформлена по системе дизайна ШИБЕЙС (сервис «База знаний»): Acari Sans, Ambidexter для логотипа, светлая и тёмная темы. Открывается локально в браузере, нужен только интернет для загрузки d3.

- Вкладка «Ваш путь»: анкета по спецификации `data/anketa-i-rekomendacii.md`. 31 вопрос и 5 вопросов профиля, восемь осей, два ближайших архетипа, три человека с похожим стартом, советы с действием на 90 дней. Логика в `anketa.js`, расчёт идёт в браузере.
- Четыре слоя: ядро (98), первая сотня кандидатов (100), второй эшелон (100), третья сотня (100).
- Фильтры по группе, категории узла, надёжности данных, году рождения.
- Портреты 279 человек из Wikimedia Commons, с автором и лицензией в карточке и в сводке.
- Карточка человека: фото, сейчас, в 18–25 лет, взлёт, точки пересечения, прямые связи, с кем пересекается.
- «Как связаны»: кратчайшая цепочка между двумя людьми с пояснением каждого шага.
- Вкладка «Список»: сортируемая таблица со всеми карточками.
- Вкладка «Сводка»: статистика и выводы.

Источники данных: `data/dosye-elita.md` и `data/dosye-elita-tretya-sotnya.md`. Шрифты системы дизайна в `fonts/`. Сборка описана в `tools/README.md`.
