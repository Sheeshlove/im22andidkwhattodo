# Как развернуть сайт

Сайт статический: одна страница `index.html` и файлы рядом с ней. Сервер не выполняет никакого кода, база данных не нужна. Анкета считает результат в браузере посетителя.

Что должно лежать на сервере:

| Путь | Что это |
|---|---|
| `index.html` | страница со всеми данными внутри |
| `anketa.js` | логика анкеты «Ваш путь» |
| `img/` | портреты, около 3 МБ |
| `fonts/` | шрифты системы дизайна ШИБЕЙС |

Папки `data/`, `tools/`, `deploy/` и `tests/` нужны только для пересборки и проверки, посетителям их отдавать не надо. Скрытые папки `.agents/` и `.claude/` хранят навыки для агентов, конфиг nginx их тоже не отдаёт.

Два внешних адреса должны быть доступны у посетителя: cdnjs.cloudflare.com, откуда грузится d3, и ui-sdk.dev, откуда грузятся компоненты ui-sdk и их стили.

Открыть `index.html` двойным щелчком не получится: браузер не загрузит шрифты и `anketa.js` с локального диска. Нужен хотя бы простой веб-сервер.

## Вариант 1. Посмотреть у себя на компьютере

Из папки репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000 в браузере.

## Вариант 2. Свой сервер с nginx

Подойдёт любой VPS с Ubuntu 22.04 или 24.04 и доменом, который указывает на IP сервера (запись A в DNS). Готовый конфиг лежит в `deploy/nginx.conf`, он проверен на nginx 1.24.

**1. Установите nginx и git.**

```bash
sudo apt update
```

```bash
sudo apt install -y nginx git
```

**2. Скачайте сайт.** Если репозиторий приватный, git попросит логин и токен GitHub, либо настройте ключ развёртывания (Deploy key) в настройках репозитория.

```bash
sudo git clone https://github.com/sheeshlove/im22andidkwhattodo.git /var/www/elita
```

**3. Подключите конфиг.** Замените в нём `example.ru` на свой домен.

```bash
sudo cp /var/www/elita/deploy/nginx.conf /etc/nginx/sites-available/elita
```

```bash
sudo nano /etc/nginx/sites-available/elita
```

```bash
sudo ln -s /etc/nginx/sites-available/elita /etc/nginx/sites-enabled/elita
```

Если на сервере больше ничего нет, отключите страницу nginx по умолчанию:

```bash
sudo rm /etc/nginx/sites-enabled/default
```

**4. Проверьте конфиг и перезапустите nginx.**

```bash
sudo nginx -t
```

```bash
sudo systemctl reload nginx
```

Сайт откроется по адресу http://ваш-домен.

**5. Включите HTTPS.** Certbot сам получит бесплатный сертификат Let's Encrypt, допишет его в конфиг и будет продлевать.

```bash
sudo apt install -y certbot python3-certbot-nginx
```

```bash
sudo certbot --nginx -d example.ru -d www.example.ru
```

**6. Откройте порты**, если включён файрвол ufw:

```bash
sudo ufw allow 'Nginx Full'
```

### Как обновлять

После каждого пуша в `main` выполните на сервере:

```bash
sudo git -C /var/www/elita pull
```

Перезапускать nginx не нужно. Страница отдаётся с заголовком `no-cache`, поэтому посетители увидят новую версию сразу. Фото и шрифты кэшируются на неделю и месяц.

### Что делает конфиг

- Отдаёт `.ttf` и `.otf` с правильным типом: в стандартном списке nginx их нет.
- Закрывает `.git`, `tools/`, `deploy/`, `tests/`, `node_modules/` и все скрытые папки ответом 404.
- Сжимает страницу: 516 КБ превращаются примерно в 150 КБ.
- Кэширует фото, шрифты и скрипты, но не саму страницу.

## Вариант 3. GitHub Pages

Самый простой способ без своего сервера.

1. В репозитории откройте Settings, затем Pages.
2. В поле Source выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Нажмите Save.
3. Через минуту-две сайт появится по адресу `https://sheeshlove.github.io/im22andidkwhattodo/`.

Каждый пуш в `main` обновляет сайт сам. Ограничения: для приватного репозитория Pages работает только на платных тарифах GitHub. Папки `tools/`, `tests/` и `data/` на Pages будут доступны по прямой ссылке. Секретов в них нет, но если это мешает, используйте вариант с nginx.

Свой домен подключается там же, в поле Custom domain.

## Проверка перед выкладкой

На своей машине, до пуша в `main`:

```bash
npm test
```

Тесты проверяют данные, анкету, сценарии в браузере и, если установлен nginx, сам конфиг из `deploy/nginx.conf`. Подробности в `tests/README.md`.

## Перед публичным запуском

- **Фото.** Портреты взяты из Wikimedia Commons под свободными лицензиями. Авторы и лицензии перечислены в сводке, блок «Фотографии». Этот список должен оставаться на сайте: лицензии CC BY требуют указывать автора.
- **Шрифты.** Acari Sans и Ambidexter взяты из системы дизайна ШИБЕЙС. Перед публикацией проверьте, что их лицензии разрешают раздавать файлы шрифтов с сайта.
- **Реальные люди.** Спецификация анкеты требует не показывать записи с низкой надёжностью, пока их не проверят. На схеме они пока видны: фильтр «низкая» включён по умолчанию.

## Если что-то не работает

| Признак | Причина |
|---|---|
| Схема пустая, в консоли ошибка про `d3` | Нет доступа к cdnjs.cloudflare.com у посетителя |
| Текст набран Arial, а не Acari Sans | Папка `fonts/` не загружена или сервер отдаёт шрифты с неверным типом |
| Вместо фото цветные точки | Не загружена папка `img/` |
| Компоненты ui-sdk не работают или без стилей | Нет доступа к ui-sdk.dev у посетителя |
| Вкладка «Ваш путь» пустая | Не загружен `anketa.js` или страница открыта с диска, а не через сервер |
| `403 Forbidden` от nginx | У пользователя `www-data` нет прав на чтение папки: `sudo chmod -R o+rX /var/www/elita` |
