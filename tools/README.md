# Сборка

Страница `index.html` не правится вручную. Она собирается из трёх источников:

| Что | Где |
|---|---|
| Досье: люди, узлы, прямые связи ядра | `data/dosye-elita.md`, `data/dosye-elita-tretya-sotnya.md`, `data/dosye-elita-chetvyortaya-sotnya.md` |
| Ручная привязка кандидатов к узлам и описания новых узлов | `tools/mapping.py` |
| Фото, авторы и лицензии | `data/photos.json`, файлы в `img/` |

Пересборка одной командой из любой папки:

```bash
tools/rebuild.sh
```

Скрипт разбирает досье (`tools/parse.py`), подмешивает привязку и фото (`tools/build.py`), пишет `data/graph.json` и вставляет его в шаблон `tools/template.html`, получая `index.html`. Если в привязке есть имя или узел, которых нет в данных, сборка остановится и покажет ошибки. Нужен только Python 3.

Анкета не встраивается в страницу: её логика лежит в `anketa.js` и подключается отдельным файлом.

## Как добавить человека

1. Добавьте карточку в досье в том же формате, что у соседей.
2. Допишите его номер в `tools/mapping.py`: узлы с ролью и прямые связи. Новый узел опишите в `NEW_NODES`.
3. Запустите `tools/rebuild.sh`, затем `npm test`.

## Фотографии

Скрипты в `tools/photos/` ищут портреты в Wikidata через SPARQL и качают превью с Wikimedia Commons.

| Скрипт | Что делает |
|---|---|
| `wdfast.py` | Основной поиск для всех, у кого ещё нет фото: сначала по полному имени, затем по фамилии. Принимает запись, только если совпадают имя и год рождения ±1 |
| `wd.py`, `wd2.py` … `wd8.py`, `pick.py` | Ранние проходы по отдельным сотням, оставлены для истории |
| `dl.py` | Качает превью шириной 160px в `img/` |
| `credits.py` | Собирает автора и лицензию каждого файла с Commons |

Результат складывается в `data/photos.json`, который `tools/build.py` подмешивает в карточки. Wikidata ограничивает частоту запросов, поэтому поиск идёт пакетами по 2–4 имени с паузами. Полный проход по двумстам людям занимает около часа.
