# Тесты

Встроенный раннер Node (`node:test`) и Playwright. Отдельный тестовый фреймворк не нужен.

| Файл | Что проверяет | Нужно |
|---|---|---|
| `data.test.cjs` | Целостность данных: пять слоёв, уникальные имена, узлы и связи ведут к существующим людям, фото на месте и с лицензией, векторы четвёртой сотни. Что `index.html` и `data/graph.json` совпадают с пересборкой из досье | Node, Python 3 для проверки пересборки |
| `anketa.test.cjs` | Логику анкеты по спецификации: максимумы осей, девять архетипов, центрированное сходство, пример из раздела 9, правила отчёта на 400 случайных анкетах | Node, Chromium |
| `ui.test.cjs` | Сценарии в браузере: слои, поиск, «Как связаны», список, анкета кликами, тёмная тема, телефон 375px без горизонтальной прокрутки | Node, Chromium, интернет для d3 и ui-sdk |
| `deploy.test.cjs` | Конфиг `deploy/nginx.conf` на настоящем nginx: типы файлов, закрытые служебные папки, сжатие | nginx, иначе тест пропускается |

Запуск всех тестов:

```bash
npm test
```

Одного набора:

```bash
npm run test:anketa
```

Одного теста по названию:

```bash
node --test --test-name-pattern="Как связаны" tests/ui.test.cjs
```

Страница открывается прямо с диска, сервер для тестов не нужен. Если `index.html` устарел, первый тест в `data.test.cjs` скажет, что его нужно пересобрать командой `tools/rebuild.sh`.
